# Состав данных и SQL

Источник — предоставленная учебная база `alpha_cinema` курса по анализу данных IT Minimalist. В репозиторий включены минимальные CSV для автономного воспроизведения, без полей имени, контактов и других персональных атрибутов клиентов. Идентификаторы используются как ключи учебного набора.

| Файл в `data/raw/` | Строк | Содержание |
|---|---:|---|
| `schedule.csv` | 1 963 | Дата, часть дня, кинотеатр, зал и фильм. |
| `films_payments.csv` | 9 643 | Билетные строки: сеанс, клиент, канал, время оплаты. |
| `films.csv` | 53 | Идентификатор/название фильма и цена билета. |
| `clients.csv` | 9 573 | Только `client_id` и `discount_perc`. |
| `dict_cinema_rooms.csv` | 9 | Вместимость и признаки VIP/3D для залов. |
| `bar_payments.csv` | 16 875 | Клиент, время, товар и цена до объявления политики очистки. |

Данные сгенерированного A/B-теста и экспериментальные назначения не публикуются: эксперимент не проводился. Исходный журнал посещений сайта не нужен для воспроизведения текущего дашборда и не включён. Дизайн теста содержит требования к будущему логированию.

## Путь обработки

`CSV → проверки ключей и JOIN → билетный факт → витрины сеансов/клиентов → агрегации → DataLens`.

`src/build_from_raw.py` - воспроизводимый автономный путь. Он не запрашивает доступ к базе. В `results/` сохранены только компактные контрольные итоги и сводные таблицы; полные витрины генерируются в `data/processed/`.

## SQL-файлы

- `tickets_enriched.sql` - адаптация SQL учебного проекта с CTE, JOIN, оконными расчётами и месяцем по дате сеанса. Гранулярность - билетная строка; оконные значения сеанса нельзя суммировать как независимые продажи.
- `session_metrics.sql` — подготовленный вариант витрины от полного расписания, с сохранением нулевых продаж.
- `quality_checks.sql` — подготовленные read-only проверки исходной базы.

Эти версии SQL не выполнялись на сервере в рамках опубликованной проверки. Локальные проверки и результаты основаны на приложенных CSV и pandas. Не следует представлять SQL-шаблоны как подтверждённые серверные запуски.
